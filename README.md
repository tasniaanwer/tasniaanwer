## Hi, I'm Tasnia 👋

I build web applications with **React, TypeScript, Node.js, and Express**, connecting responsive interfaces with backend services and databases.

My projects span custom form builders, email automation, e-commerce backends, and database applications. I enjoy turning practical ideas into useful software and strengthening my skills through hands-on development.

- **Frontend:** responsive interfaces with React, TypeScript, HTML, and CSS.
- **Backend:** Node.js, Express, MongoDB, and authentication workflows.
- **Foundations:** Java, C++, C#, algorithms, and database projects.
